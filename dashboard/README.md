# Dashboard

The first Tableau Public release will contain four views:

1. Regional stop heat-risk map.
2. Stop detail with transparent score components.
3. Route and neighborhood equity comparison.
4. Ranked heat-mitigation investment priorities.

The dashboard will display the reporting period, source dates, methodology link,
and limitations. Tableau workbook files and extracts are excluded from Git until
the public-data review and publishing workflow are finalized.
